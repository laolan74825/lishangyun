## 七、风险与注意事项

1. **桌面端断点调整** — 从 800px 改为 1280px 后，800-1280px 区间（平板横屏）将使用移动端布局。需回归测试此宽度区间的可用性，可能需要增加中间断点。

2. **SettingsPage 用户管理迁移** — SettingsPage 已有基础用户管理（创建/编辑/禁用），P3 需迁移到 AdminUsersPage 并增强。迁移期间保持两处可用，避免功能回退。

3. **addOperationLog 清理** — 操作日志由后端 `write_audit_log()` 自动创建。`api-client.ts` 中的桩函数应移除，同时清理所有调用点（搜索 `addOperationLog` 确认无遗漏）。

4. **TypeScript 严格模式** — 每个 P 阶段结束时运行 `tsc --noEmit` 确保零错误。新功能必须完整类型定义。

5. **ECharts 内存管理** — ECharts 实例需要在组件卸载时调用 `chart.dispose()` 释放资源，避免内存泄漏。使用 `useEffect` cleanup 函数处理。

6. **API 函数补充节奏** — P1 中批量补充账户管理/差额调整/增强统计的 API 函数，P5 补充合并/代理函数。建议在 `api-client.ts` 中按模块分区，保持代码组织清晰。

7. **`useCachedGuestbook` 评估** — 第三个已实现但未使用的 hook。在 P2 阶段评估是否需要接入 GuestbookDetailPage，如确认为冗余代码可移除。

## 六、技术架构摘要

### 6.1 技术栈

- **框架：** Python 3.14 + FastAPI 0.141+ + SQLAlchemy 2.0 (async ORM)
- **数据库：** PostgreSQL 17（开发/生产统一）
- **迁移：** Alembic 1.20+（autogenerate + 离线模式）
- **认证：** PyJWT 3 (HS256) + Argon2 (passlib)
- **实时：** websockets 17+（房间模式，礼簿协作）
- **加密：** cryptography (AES-256) + Web Crypto API (客户端)
- **包管理：** uv 0.12+

### 6.2 核心模式

| 模式 | 实现 |
|------|------|
| 数据隔离 | owner_id 过滤（149 处） |
| 软删除 | is_deleted + deleted_at（5 张表） |
| 审计日志 | write_audit_log()（target_table + target_id） |
| UUID | 服务端生成（uuid4） |
| 金额 | Integer 分（范围 100 ~ 10000000） |
| 分页 | paginate_query()（page/page_size） |
| 同步 | sync_version 增量 + _pendingSync 离线队列 |
| 隐私 | is_private 标记（仅本人可见） |
| 角色 | 5 级：super_admin / admin / user / family_member / collaborator |
| 礼簿状态 | 三态：收礼中 → 收尾中 → 已归档（不可逆） |

## 七、与前端对接指南

### 7.1 前端需对接的 API 模块

按优先级排序：

1. **数据导入导出**（M1）— import/export API + 模板下载
2. **同步引擎**（M2）— sync pull/push + WebSocket 连接
3. **家庭共享**（M3）— family API + 授权码 + 代记
4. **审批通知**（M4）— approvals + notifications API
5. **安全模式**（M5）— security config + 助记词
6. **高级功能**（M6）— 人员合并 + 差额调整 + 增强统计

### 7.2 前端类型定义更新

`web/src/types/index.ts` 需补充以下类型（与后端 Schema 对齐）：

- `AuthorizationActionLog` — 授权码操作日志
- `PaginatedResponse<T>` — 分页响应信封
- `SyncPullRequest/Response` — 同步协议类型
- `Conflict` — 冲突数据结构
- `PendingApproval` — 补充 `data_snapshot`、`expires_at`、`family_group_id` 字段

### 7.3 关键接口约定

- 所有金额字段为 Integer（单位：分），前端展示时 `/100` 转元
- 分页参数：`page`（从 1 开始）、`page_size`（默认 20，最大 100）
- 分页响应：`{ items: T[], pagination: { page, page_size, total_count, total_pages } }`
- 日期格式：ISO 8601（`2026-09-26T10:30:00Z`）
- 错误响应：`{ detail: "错误描述" }`（HTTPException）

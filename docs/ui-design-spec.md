> 文档版本：v3.0
> 配套需求：礼尚云需求分析 v4.1 + 用户管理需求规划 v2.3
> 编制日期：2026-09-07
> 现代化更新：2026-09-21

> 设计目标：宴席现场高频操作场景下的极致易用性 + 多用户管理与协作场景的完整覆盖
> CSS 方案：Tailwind CSS 4（CSS-first @theme 配置）+ 现代 CSS 特性（容器查询、:has()、CSS Layers）

## 一、设计原则

### 1.1 核心原则

| 原则 | 说明 | 设计体现 |
| ------ | ------ | ---------- |
| **大字优先** | 宴席现场嘈杂、光线复杂，必须确保信息一眼可读 | 标题 20px+，正文 16px+，金额 32px+ |
| **三步完成** | 核心收礼操作（姓名→金额→提交）不超过 3 步 | 减少表单字段，智能默认填充 |
| **防错优先** | 金钱操作不容出错，任何提交前必须有确认机制 | 强制选择收款方式、重名提醒、二次确认 |
| **实时反馈** | 操作结果必须立即可见，消除不确定感 | 实时合计、同步状态、最近记录展示 |
| **单手操作** | 现场记账常单手持机，按钮布局适配拇指热区 | 底部固定操作区、大点击区域（≥48px） |

### 1.2 用户画像

| 角色 | 年龄段 | 核心需求 | 设计要点 |
| ------ | -------- | ---------- | ---------- |
| **主人家** | 40-60岁 | 账目安全、对账报表、家庭数据共享 | 大字体统计、清晰的对账进度、家庭组管理入口 |
| **记账员** | 20-50岁 | 现场快速录入、大字号、少步骤 | 三步完成收礼、智能默认填充、大点击区域 |
| **宾客** | 全年龄段 | 送完礼后核对记录 | 最近记录实时展示、翻页核对 |
| **超级管理员** | IT运维 | 系统运维、用户管理、安全审计 | 桌面端管理后台、仪表盘、审计日志 |
| **家庭成员** | 20-60岁 | 协作维护共享记账本、审批操作 | 邀请处理、审批队列、隐私标记 |
| **临时协作者** | 20-50岁 | 通过授权码参与特定礼簿收礼 | 授权码绑定、受限操作界面 |

### 1.3 设备适配策略

| 设备 | 使用场景 | 设计策略 |
| ------ | ---------- | ---------- |
| 手机（竖屏） | 记账员手持快速录入、日常记账、通知查看 | 单列布局，底部固定操作栏 |
| 平板（横屏） | 固定桌面供宾客核对 / 代理送礼批量录入 | 左右分栏，左侧录入区 + 右侧记录列表 |
| 平板（竖屏） | 灵活摆放 | 与手机同布局，元素适当放大 |
| 电脑（桌面端） | 主人家深度管理、管理后台、统计分析、家庭管理、系统配置 | 顶部导航 + 侧边栏 + 主内容区，高信息密度 |

### 2.5 Tailwind CSS 4 实现方案

Tailwind CSS 4 采用 CSS-first 配置，通过 `@theme` 指令在 CSS 文件中定义设计 Token，无需 `tailwind.config.js`。

```css
/* src/styles/theme.css — Tailwind CSS 4 @theme 配置 */
@import "tailwindcss";

@theme {
  /* ── 色彩 Token ── */
  --color-primary-50:  #FFF3EB;
  --color-primary-100: #F5A76E;
  --color-primary-500: #E07B3A;   /* 主色-中：主按钮/提交 */
  --color-primary-700: #C45C26;   /* 主色-深 */

  --color-success-50:  #E8F5E9;
  --color-success-100: #74C69D;
  --color-success-500: #40916C;   /* 成功/已对账 */
  --color-success-700: #2D6A4F;

  --color-danger-500:  #C0392B;   /* 错误/禁用/限额已满 */
  --color-warning-500: #E67E22;   /* 警告/限额紧张 */
  --color-info-500:    #3498DB;   /* 信息/链接 */

  --color-neutral-900: #1A1A1A;   /* 文字主色 */
  --color-neutral-500: #666666;   /* 文字次要 */
  --color-neutral-50:  #F5F5F0;   /* 页面背景 */

  --color-gold-500:    #D4AF37;   /* 金色强调 */
  --color-gold-50:     #FFF8E7;   /* 金色浅底 */

  /* ── 间距 Token ── */
  --spacing-xs:  4px;
  --spacing-sm:  8px;
  --spacing-md:  16px;
  --spacing-lg:  24px;
  --spacing-xl:  32px;
  --spacing-2xl: 48px;

  /* ── 圆角 Token ── */
  --radius-btn-primary: 12px;
  --radius-btn-secondary: 8px;
  --radius-card: 16px;
  --radius-input: 12px;
  --radius-modal: 20px;

  /* ── 阴影 Token ── */
  --shadow-card: 0 2px 8px rgba(0,0,0,0.06);
  --shadow-input-focus: 0 0 0 3px rgba(224,123,58,0.2);
  --shadow-modal: 0 8px 24px rgba(0,0,0,0.12);
  --shadow-qrcode: 0 4px 12px rgba(0,0,0,0.08);

  /* ── 动画时长 Token ── */
  --duration-fast: 150ms;     /* 微交互：hover/active 状态切换 */
  --duration-normal: 250ms;   /* 页面内过渡：Tab 切换、下拉展开 */
  --duration-slow: 300ms;     /* 弹窗/页面转场 */
  --duration-modal: 300ms;    /* 弹窗入场动画 */

  /* ── 语义色映射 ── */
  --color-bg-page: var(--color-neutral-50);      /* 页面背景 */
  --color-bg-card: #FFFFFF;                       /* 卡片背景 */
  --color-bg-sidebar: #FFFFFF;                    /* 侧边栏背景 */
  --color-bg-navbar: var(--color-neutral-900);    /* 顶部导航背景 */
  --color-text-primary: var(--color-neutral-900); /* 主文字 */
  --color-text-secondary: var(--color-neutral-500); /* 次要文字 */
  --color-text-inverse: #FFFFFF;                  /* 深色背景上的文字 */
  --color-border-default: #E8E8E3;                /* 默认边框 */
  --color-border-focus: var(--color-primary-500); /* 聚焦边框 */

  /* ── 字体栈 ── */
  --font-sans: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC',
               -apple-system, BlinkMacSystemFont, sans-serif;

  /* ── 断点（Tailwind CSS 4 使用 @custom-media 或直接在 @media 中使用） ── */
  --breakpoint-sm: 640px;
  --breakpoint-md: 1024px;
  --breakpoint-lg: 1280px;
  --breakpoint-xl: 1440px;
  --breakpoint-2xl: 1920px;
}
```

**使用示例：**

```html
<!-- 主按钮：直接使用 Token 类名 -->
<button class="bg-primary-500 hover:bg-primary-700 text-white rounded-btn-primary
               px-spacing-md py-spacing-sm text-base font-bold
               active:scale-96 transition-transform">
  记一笔
</button>

<!-- 卡片：使用阴影和圆角 Token -->
<div class="bg-white rounded-card shadow-card p-spacing-md">
  <span class="text-neutral-900 font-bold text-2xl">¥ 12,800</span>
</div>

<!-- 容器查询：卡片内部根据容器宽度自适应布局 -->
<div class="@container">
  <div class="grid grid-cols-1 @md:grid-cols-2 @lg:grid-cols-3 gap-spacing-md">
    <!-- 记录项根据容器宽度自动调整列数 -->
  </div>
</div>

<!-- :has() 选择器：表单验证状态样式 -->
<form class="has-[input:invalid]:border-danger-500">
  <input type="number" required />
</form>
```

**现代 CSS 特性应用：**

| 特性 | 场景 | 实现方式 |
| ------ | ------ | ---------- |
| 容器查询 (`@container`) | 卡片/组件内部响应式 | 组件根据父容器宽度而非视口宽度调整布局 |
| `:has()` 选择器 | 表单验证、父级状态 | 父元素根据子元素状态（invalid/checked/focus）改变样式 |
| CSS Layers (`@layer`) | 样式优先级管理 | Tailwind 4 内置 layers：`@layer theme, base, components, utilities` |
| `color-mix()` | 悬停/禁用态颜色 | `color-mix(in srgb, var(--color-primary-500), black 15%)` |
| `@starting-style` | 入场动画起始状态 | 配合 `transition-behavior` 实现元素首次渲染动画 |

**交互细节：**

- **金额输入**：点击后唤起大字号数字键盘（非系统键盘），支持退格和清零
- **收款方式**：默认都不选中（灰色边框），选中后填充橙色底+白色文字
- **收款人切换**：点击「切换」弹出底部选择器，列出所有启用中的同类型账户
- **二维码**：仅在选择「微信」时显示；切换微信账户时，二维码图片 300ms 淡入淡出过渡更换
- **提交按钮**：校验未通过时（缺姓名/金额/方式）显示 `#CCCCCC` 灰色禁用态；通过后变为 `#E07B3A` 橙色可点击
- **最近记录**：每 5 秒自动刷新；支持左右滑动翻页；新记录录入后顶部插入，带淡入动画

- 顶部导航栏：固定高度 64px，深色背景 `#1A1A1A`，白色文字

- 导航项条件显示：「家庭管理」始终可见；「授权码」始终可见；「管理后台」仅 `super_admin` / `sub_admin` 角色可见

- 侧边栏：固定宽度 280px，浅色背景 `#FFFFFF`，右侧 1px 分隔线 `#E8E8E3`
- 主内容区：自适应剩余宽度，最小 960px，内边距 32px
- 底部状态栏：固定高度 32px，显示同步状态、当前礼簿、快捷键提示

## 七、响应式断点

| 断点 | 设备 | 布局策略 | Tailwind CSS 4 实现 |
| ------ | ------ | ---------- | --------------------- |
| < 640px | 手机竖屏 | 单列布局，底部固定操作栏 | 默认样式（mobile-first） |
| 640px - 1023px | 平板竖屏 / 大手机 | 单列布局，元素适当放大（1.1x） | `@media (width >= 640px)` / `sm:` |
| 1024px - 1279px | 平板横屏 | 左右分栏，左侧录入 + 右侧展示 | `@media (width >= 1024px)` / `md:` |

| 1440px - 1919px | 标准桌面 | 顶部导航 + 侧边栏 280px + 主内容区，高信息密度，图表并排 | `xl:` |

**容器查询补充：** 组件内部布局使用容器查询（`@container`）实现真正的组件级响应式，不依赖全局视口宽度。例如收礼记录卡片在窄容器中单列显示，在宽容器中自动切换为双列。

## 九、功能流程设计

### 9.1 安全模式切换向导

> 从普通模式切换到增强模式（客户端加密），需要备份恢复助记词

**流程步骤：**

```text
① 说明页 → ② 生成助记词 → ③ 抄写确认 → ④ 验证助记词 → ⑤ 设置密码 → ⑥ 完成
```

**① 说明页：**

```text
┌─────────────────────────────────────────┐
│  ← 开启增强安全模式                      │
├─────────────────────────────────────────┤
│                                         │
│           🔒 增强安全模式                │
│                                         │
│  开启后，您的数据将使用 AES-256-GCM      │
│  端到端加密，密钥仅保存在您的设备上。     │
│                                         │
│  ── 您需要了解 ──                        │
│                                         │
│  ✅ 数据在云端加密存储，服务商无法读取     │
│  ✅ 跨设备同步需要输入密码或助记词        │
│  ⚠️ 忘记密码且丢失助记词 = 数据不可恢复  │
│  ⚠️ 家庭共享成员需各自持有密钥副本        │
│                                         │
│  ┌─────────────────────────────────┐    │

│                                         │
└─────────────────────────────────────────┘
```

**③ 抄写确认 + ④ 验证：**

- 展示 12 个助记词（参见组件 §5.14）
- 点击「我已抄写」后随机要求输入 3 个位置的单词
- 验证通过后进入密码设置步骤

**⑤ 设置加密密码：**

- 密码用于在新设备上解锁加密数据
- 需输入两次确认，密码强度实时检测（参见组件 §5.6）
- 最低要求：8位，含大小写字母和数字

**交互细节：**

- 切换过程中显示进度条，数据加密在后台执行
- 加密完成后自动刷新页面，导航栏显示 🔒 加密标识
- 反向切换（增强→普通）需输入密码确认，参见需求分析 F-9.7 安全模式说明

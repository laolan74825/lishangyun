# 2026-10-08 统计报表功能增强与导航调整汇总

起因：使用反馈提出统计报表页的年度总览缺少净差额、事由需显示中文、人员排行需展示名字/称谓/备注等。随后对统计报表页做了一轮整体改进（分析建议 10 项 + 工程项 3 项全部落地），并调整顶部导航。前后端测试全绿（后端 341、前端 180）。

## 一、API 契约变更（重要，后续开发请遵守）

### `GET /stats/overview`

- 新增返回字段：`adjustment_total`（差额调整合计）、`net_with_adjustment`（含调整的净差额 = 收到 − 送出 + 差额调整）
- 原有 `total_out` / `total_in` / `net`（不含调整）保持不变，首页继续用原口径
- 差额调整的日期过滤按 **created_at**（调整操作时间），与收支按数据日期的口径不同，属有意为之

### `GET /stats/event-distribution`

- 新增查询参数 `type=in|out`（默认 `in`）：`in` 统计收到 = 日常收 + 礼簿收礼；`out` 仅统计日常送出（礼簿无送出概念）

### `GET /stats/person-ranking`

- 新增返回字段：`nickname`、`relationship_tag`、`note`
- 新增查询参数 `sort=out|in|net`（默认 `net`，保持原 |净额| 排序）：`out` 按送出降序、`in` 按收到降序

## 二、统计报表页改进

### 口径统一

- 「本年净差额」「累计净差额」改用 `net_with_adjustment`，与人员排行的「净」（含差额调整）口径一致；副标题注明，有调整时显示一行差额调整金额
- 顺带修复存量 bug：前端排行类型误用 `r.name`，与后端返回的 `person_name` 不匹配，排行名字此前渲染为空

### 交互

- 年份选择器改为左右箭头切换，范围动态生成（当前年 −10 ～ 当前年 +1），不再写死 2023–2026
- 按事由统计支持「收到 / 送出」切换（送出仅含日常随礼，页面有说明）
- 月度趋势支持 12 / 24 / 36 个月切换
- 人员排行支持「按净额 / 按送出 / 按收到」排序和 Top 10 / 20 / 50
- 排行条目可点击跳转人员详情页（`/people/:id`）

### 展示

- 每个卡片标注统计范围（「全部时间」「全部礼簿」等），消除年份切换的误导
- 月度趋势悬停提示补回月份标题（原 formatter 覆盖后丢失）
- 事由分布悬停提示增加占比百分比；图表网格改 `containLabel` 自适应，中文长事由不再截断
- 对账进度改为汇总进度条（已对账 x/y 笔 + 百分比 + 金额对账）
- 整页单一加载改为各卡片独立加载

## 三、事由中文映射统一

- 新增共享模块 `web/src/lib/eventType.ts`：`EVENT_TYPE_LABELS` + `eventTypeLabel()`，未知值（历史自由文本）原样展示
- 替换三处重复定义：记录列表页、人员详情页、打印礼单模块（`printGuestbook.ts`）
- 顺带修复：打印模块原映射缺 `engagement`（订婚）、`birthday_banquet`（生日/寿宴），统一后打印可正确显示

## 四、导航调整

- 顶部导航栏移除「数据导入」入口（现有：礼簿管理 / 人员管理 / 统计报表 / 账户管理）
- `/import` 路由与页面保留，礼簿管理页「整本礼簿导入」直达入口不受影响

## 五、工程项

- 新增 `formatFen()`（`web/src/lib/format.ts`）：分 → `-¥x.xx`，统计页 / 礼簿汇总表 / 首页三处重复格式化已收敛（人员详情页 `types/index.ts` 的 `formatAmount` 只返回数值不带 ¥，语义不同，保留）
- `api-client.ts` 导出 `relationTagLabel`（关系标签英文枚举 → 中文显示值），供排行等场景复用
- 两个 ECharts 组件（月度趋势、事由分布）改为数据变化时增量 `setOption`，不再销毁重建实例

## 六、测试

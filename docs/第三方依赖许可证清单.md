## 四、义务与维护要求

1. **保留声明**：宽松许可证（MIT/BSD/Apache-2.0）的唯一实质义务是**保留版权与许可声明**。构建前端产物时 Vite 默认保留各包 license 注释；建议在官网/应用内"关于"页或分发包中附一份第三方声明（本清单即可作为底稿）。
2. **加依赖即更新**：每次新增依赖，在本清单追加一行；禁止在未核查许可证前引入新包。
3. **CI 卡口（建议后续接入）**：
   - 前端：`pnpm licenses list --prod` 输出比对本清单，出现 `GPL/AGPL/SSPL/CDDL` 即失败；
   - 后端：`pip-licenses`（`pip install pip-licenses`，在 `server/.venv` 内运行）同样设黑名单。
4. **预警项**：ECharts 历史上曾调整过授权策略（其 zrender 生态个别衍生库为非商业授权），升级 echarts 大版本前复查一次许可证。
